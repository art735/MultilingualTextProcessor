Порядок действий при установке "с нуля":

1. Установить "общие" пакеты (т. е. все, кроме языковых) запустив script_install_1_general_packages

2. Установить языковые пакеты для spaCy запустив script_install_2_spacy_lang_packages.
Языковые пакеты вынесены в отдельный файл, чтобы при обновлении пакетов с помощью скрипта script_upgrade_general_packages, они не скачивались бы каждый раз заново с huggingface.co по .whl-ссылкам.

Порядок действий при обновлении пакетов:

При изменении версий пакетов запускать скрипт script_upgrade_general_packages: он обновит пакеты с учётом их совместимости между собой и с учётом всех их зависимостей, и при этом языковые пакеты с huggingface.co повторно скачиваться не будут.
