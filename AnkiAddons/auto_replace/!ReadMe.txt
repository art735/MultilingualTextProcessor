1. Перейти в папку, содержащую addons:
%APPDATA%\Anki2\addons21

2. Создать папку auto_replace для новосоздаваемого addon-а

3. В папку auto_replace поместить файл `__init__.py` (из текущей папки проекта)

При добавлении/изменении `__init__.py` всегда закрывать Anki и открывать заново (просто выход из профиля и повторный
вход в него без полного закрытия/открытия Anki не будет подхватывать изменения).

При добавлении данного addon-а в меню Tools появится новый пункт "Custom auto replace" с возможностью вызова его через
shortcut Ctrl+Alt+M (мой стандартный shortcut для вызова автозамен во всех средах: OO Writer, Npp, Anki).
